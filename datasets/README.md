# Datasets

Datasets are not included in this repository. Download them from Kaggle and place them in the **project root** (not this folder).

## Credit Card Fraud Detection

- **Source:** https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
- **File name:** `creditcard.csv`
- **Size:** ~150 MB, 284,807 rows, 30 features (V1–V28 are PCA-transformed)
- **Imbalance:** 0.17% fraud (492 of 284,807 transactions)

## German Credit Risk

- **Source:** https://www.kaggle.com/datasets/kabure/german-credit-data-with-risk
- **File name:** `german_credit_data.csv`
- **Size:** ~50 KB, 1,000 rows, 9 features
- **Imbalance:** 30% bad credit (300 of 1,000 cases)

## Placement

After downloading, place both files in the project root:

```
fraude-detection-project/
├── creditcard.csv          ← here
├── german_credit_data.csv  ← here
├── src/
├── results/
└── ...
```
